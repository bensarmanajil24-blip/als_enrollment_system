ALS ENROLLMENT SYSTEM - SETUP (XAMPP)

1. Install and open XAMPP. Start Apache and MySQL.
2. Extract the folder `als_enrollment_system` into `C:\xampp\htdocs\`.
3. Open http://localhost/phpmyadmin
4. Choose Import, select `database.sql`, then click Import/Go.
5. Check `db.php`. Default XAMPP settings are host=localhost, user=root, password blank.
6. Open http://localhost/als_enrollment_system/create_admin.php
   Create your first admin account (username 4-80 chars; password at least 10 chars).
7. IMPORTANT: After creating the admin, DELETE `create_admin.php` from the project folder.
8. Student enrollment: http://localhost/als_enrollment_system/
9. Admin login: http://localhost/als_enrollment_system/admin_login.php

FILES
- database.sql: database and tables
- db.php: PDO connection
- functions.php: escaping, session, CSRF helpers
- index.php: public enrollment form
- success.php: registration confirmation and generated student number
- admin_login.php: admin authentication
- admin_dashboard.php: search/filter, overview, status updates
- student_view.php: full student details
- logout.php: ends admin session
- create_admin.php: one-time admin account creator; delete after use
- assets/style.css, assets/app.js: responsive UI and browser validation

NOTES
- Student Number is generated by the application and is unique in the database.
- Passwords are stored using PHP password_hash() and checked with password_verify().
- Database queries use PDO prepared statements; output is escaped; forms use CSRF tokens.
- For public deployment, use HTTPS, a strong database password, secure cookie settings,
  backups, rate limiting, and your school's privacy/data-retention policies.
- This is a starter academic project, not a complete production-ready student information system.
